# Helyesírási szabályok, amelyeket a modul betart (AkH. 297. pont)

- **Kétezerig egybeírja**: 1999 → ezerkilencszázkilencvenkilenc, 2000 → kétezer.
- **Kétezer fölött hármas csoportonként kötőjellel tagol**: 1234567 → egymillió-kétszázharmincnégyezer-ötszázhatvanhét.
- **Az üres csoportok kimaradnak**: 1000001 → egymillió-egy.
- **„két” és „kettő”**: nagyobb egység előtt „két”, a szám végén „kettő”: 2002002002 → kétmilliárd-kétmillió-kétezer-kettő.
- **„tíz/tizen” és „húsz/huszon”**: 10 → tíz, 12 → tizenkettő, 20 → húsz, 22 → huszonkettő.
- **A szám elején „száz” és „ezer”, de „egymillió”**.
- **Negatív számok**: -15 → mínusz tizenöt.
- **Tizedes törtek**: 3,14 → három egész tizenhárom század.
- **Tizedes törtek, ha a tizedesvessző után nulla van**: 3,10 → három egész tíz század.
